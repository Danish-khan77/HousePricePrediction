# 🏠 House Price Prediction Web Application

A full-stack machine learning application that predicts house prices using Linear Regression.

## Tech Stack

- React
- Node.js
- Express.js
- Flask
- Python
- Scikit-learn
- Material UI

## Features

- Machine Learning Model
- Flask Prediction API
- Express Backend
- React Frontend
- Real-time Price Prediction

## Project Structure

client/
server/
ml-api/

## Run

### React

npm run dev

### Express

npm run dev

### Flask

python app.py
